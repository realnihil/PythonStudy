# 📈 토스증권 API & 파이썬 1:1 실습 스터디

> **참고 가이드:** [고구마의 토스증권 API 파이썬 완전 가이드 (총 21강)](https://gogma-log.tistory.com/50)  
> **스터디 목표:** 파이썬 기본기(HTTP 통신, 객체지향, 데이터 분석)를 다지면서, 토스증권 API를 활용한 시세 조회·계좌 관리·지표 분석을 단계별로 직접 구현해보기

---

## 🗺️ 전체 학습 커리큘럼

### [1단계] API 기초와 통신 메커니즘 (1~3강)
- [ ] **1강:** HTTP 통신 기초와 API 개념 (`requests`, REST API, JSON)
- [ ] **2강:** 토스증권 API 키 발급 및 `.env` 보안 환경 설정
- [ ] **3강:** 토스 인증(OAuth/액세스 토큰 발급)과 엔드포인트 전체 지도 살펴보기

### [2단계] 객체지향 설계와 데이터 조회 (4~7강)
- [ ] **4강:** 파이썬 클래스(`class`) 기반 재사용 가능한 API 클라이언트 설계
- [ ] **5강:** 토큰 자동 갱신 및 세션 관리
- [ ] **6강:** 국내/해외 주식 시세 조회 (현재가, 호가창, 캔들 차트)
- [ ] **7강:** 내 계좌 자산 및 보유 종목 잔고, 주문 가능 예수금 조회

### [3단계] 안정성과 데이터 분석 (8~15강)
- [ ] **8강:** 안전장치 중심의 모의 주문(`dry-run`)과 주문 라이프사이클
- [ ] **9강:** 429 Rate Limit(호출 제한)과 지수 백오프(Exponential Backoff) 재시도
- [ ] **10강:** `pandas`를 이용한 캔들 데이터 처리 및 이동평균선(SMA), RSI 보조지표 계산
- [ ] **11강:** 투자자별 수급(외인/기관) 및 공매도 데이터 분석과 조건부 종목 스크리너

### [4단계] 실무 응용과 자동화 (16~21강)
- [ ] **12강:** SQLite 로컬 데이터베이스에 시세 데이터 축적하기
- [ ] **13강:** 정기 스케줄러(`schedule`) 기반 자동 리포트 생성 및 텔레그램 알림 연동
- [ ] **14강:** 휴장일, 거래정지, 부분체결 등 실무 예외 처리 및 최종 프로젝트
