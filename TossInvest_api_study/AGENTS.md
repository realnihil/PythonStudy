# 🤖 토스증권 API 파이썬 스터디 에이전트 지침 (Toss Invest Study Rules)

이 문서는 사용자와 1:1 대화형으로 토스증권 API 및 파이썬을 학습하는 스터디 워크스페이스 전용 지침입니다.  
Antigravity 에이전트는 사용자와 대화를 시작하거나 종료할 때 아래 지침을 **반드시 자동으로 확인하고 준수**해야 합니다.

---

## 🏁 1. 세션 시작 시 (Session Start)
새로운 대화가 시작되거나 스터디를 재개할 때 에이전트는 다음을 수행합니다:

1. **학습 일지 확인 (`STUDY_LOG.md`):**
   * 대화 시작 시 가장 먼저 [STUDY_LOG.md](file:///d:/PythonStudy/TossInvest_api_study/STUDY_LOG.md)를 읽어 현재까지의 진도와 **`다음 세션 목표 (Next Up)`**를 파악합니다.
2. **오프닝 브리핑:**
   * 사용자에게 지난 세션에서 무엇을 완성했는지 1~2줄로 요약해 드립니다.
   * "오늘은 지난 시간에 이어 **[N강: 주제명]**을 진행할 차례입니다."라고 명확하게 오늘의 학습 목표를 제시하며 시작합니다.
3. **환경 체크 리마인드:**
   * 사용자가 연구소 PC나 새로운 환경에서 접속한 것으로 보이면, `git pull`과 `pip install -r requirements.txt` 및 `.env` 파일 존재 여부를 가볍게 리마인드합니다.

---

## 📖 2. 세션 진행 중 (During Session)
1. **과외식 호흡 유지:**
   * 한 번에 방대한 코드를 쏟아붓지 않고, **[개념 설명 5분] ➔ [코드 뜯어보기 5분] ➔ [직접 실행/테스트 5분] ➔ [Q&A 피드백]**의 단계를 거칩니다.
2. **코드 작성 표준:**
   * 모든 실습 코드는 `lessons/` 하위 폴더에 체계적으로 번호를 매겨 저장합니다.
   * Python 3.9 ~ 3.13 호환성을 위해 파일 상단에 `from __future__ import annotations`를 추가합니다.
   * Windows 콘솔 한글/이모지 출력을 위해 `sys.stdout.reconfigure(encoding="utf-8")` 설정을 기본 포함합니다.
3. **보안 및 안전 최우선:**
   * `.env`와 `.token_cache.json`이 절대 GitHub에 노출되거나 커밋되지 않도록 통제합니다.
   * 주문 실습 시에는 반드시 `dry_run = True`(모의 실행)를 강제하여 실제 자산이 체결되지 않도록 방어합니다.

---

## 🏁 3. 세션 종료 시 (Session Wrap-up)
사용자가 "오늘 여기까지 하자", "종료하자", "다음에 이어서 할게"라고 하거나 한 회차의 수업이 마무리되었을 때 에이전트는 다음을 **자동으로 완수**합니다:

1. **학습 일지 기록 (`STUDY_LOG.md` 업데이트):**
   * 오늘 진행한 강의 번호, 핵심 학습 내용, 작성된 실습 파일, 트러블슈팅 내역을 새로운 세션 블록(`[세션 N] YYYY-MM-DD: ...`)으로 추가합니다.
   * 상단의 `현재 진도`와 `다음 세션 목표 (Next Up)`를 최신 상태로 갱신합니다.
2. **진도표 갱신 (`README.md`):**
   * [README.md](file:///d:/PythonStudy/TossInvest_api_study/README.md)의 커리큘럼 체크박스(`[x]`)를 완료 상태로 체크합니다.
3. **원격 저장소 동기화 (Git Commit & Push):**
   * 작성된 실습 코드, `STUDY_LOG.md`, `README.md`를 Git에 커밋하고 GitHub(`origin main`)에 푸시합니다.
   * 이를 통해 연구소 PC나 다른 장소에서 바로 `git pull`하여 1초 만에 이어서 학습할 수 있도록 보장합니다.
